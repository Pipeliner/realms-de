  }

WHAT THE THEME REACHES
· gtk3/4 — one generated gtk.css: colors, borders, square corners, flat headerbars, font → IBM Plex Mono
· qt5/6 — qt6ct + Kvantum svg theme fed from the same palette file
· libadwaita — named colors via ~/.config/gtk-4.0/gtk.css (accent, window, view bg)
· terminals & TUIs — 16-color ANSI scheme, the native citizens
· electron/chromium — force dark + injected palette where supported
· cursor, icons — single mono-line icon set, no full-color mimetypes
HONEST LIMITS
· apps with hardcoded colors or bundled themes keep them
· libadwaita widget shapes (pills, big paddings) can't be fully squared — colors yes, geometry mostly no
· CSD headerbars stay client-drawn; helm just recolors them and adds its 1px border
· flatpak needs the theme granted per-app (--filesystem=xdg-config/gtk-4.0)
MECHANISM
one palette file ~/.config/helm/palette.toml → templates render gtk.css, kvantum svg, ANSI scheme, hx/nvim themes · helm ctl theme apply hot-reloads all of it
